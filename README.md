# NEON MARKET — Telegram Mini App starter

## Запуск
Нужен Node.js 20+. Установите зависимости `npm install`, задайте переменные окружения `TELEGRAM_BOT_TOKEN` и `TELEGRAM_ADMIN_IDS` (Telegram ID администраторов через запятую), затем `npm start`. Для реального Mini App нужен HTTPS-домен и настроенный URL в BotFather.

## Реализовано в интерфейсе
Тёмный серо-графитовый дизайн с неоновыми акцентами; адаптивное меню поверх страницы на мобильных устройствах; поиск, категории, сортировка, избранное, объявления, магазины, уведомления с отметкой прочитанного и подробным просмотром; разделы админки для жалоб, участников, банов, баннеров, уведомлений и логов. Демо-товары и выдуманные показатели не добавляются.

## Важно
Это стартовый проект, не готовый production-сервис. Сервер проверяет Telegram Mini App `initData`, но данные приложения сейчас сохраняются в `localStorage`, поэтому не синхронизируются между устройствами и пользователями. Административные действия в интерфейсе пока не защищены серверными API. Перед запуском обязательно подключите БД, серверные API с проверкой прав на каждое действие, безопасную сессию (HttpOnly/Secure/SameSite), серверные блокировки/модерацию/логи, реальные Telegram-уведомления, HTTPS и аудит безопасности. Никогда не храните bot token во frontend.
